# Wireframe Specifications & Screen Layouts — CoachOS

**Document version:** 1.0.0 (Phase 02 Baseline)  
**Last updated:** 2026-08-10  
**Supported Locales:** Persian (`fa-IR`, RTL) and English (`en-US`, LTR)  
**Strict constraint:** Arabic is strictly out of scope.  
**Design Phase:** Phase 02 — Documentation and specifications only. No application source code.

---

## 1. Wireframe Conventions & Layout Architecture

The wireframes below illustrate structural components, spatial hierarchies, button placements, and bidirectional mirroring across mobile, tablet, and desktop viewports.
